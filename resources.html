What OgaProp is designed to do

OgaProp is a property marketplace designed to make trust more visible. Instead of asking users to rely on a generic badge, the platform is structured so a listing can show the checks, supporting evidence and inspection status connected to that property.

Using the marketplace

The marketplace is the centre of property discovery. Users can search and narrow results using intent, area, property type, bedrooms, price and verification status, then switch between card and list views before opening a property detail page.

Understanding OgaProp verification

The verification record is intended to show what was reviewed, not simply label a property as trustworthy. Different properties can have different checks completed depending on the listing, documents available and transaction stage.

Property existence

Confirmation that the physical property or plot exists and matches the submitted listing.

Document review

Relevant ownership, title and supporting documents can be reviewed.

Identity & authority

The participant behind the listing can be tied to an accountable profile.

Verification record

Completed checks are surfaced against the property rather than hidden behind a badge.

Verification is not a substitute for legal advice.

The record should help users understand the checks performed and what evidence is available. Additional professional review may still be appropriate before a transaction is completed.

Property inspections

Eligible listings can support an in-person inspection request or a guided remote walkthrough. The goal is to make the inspection step part of the property record rather than an informal conversation outside the marketplace.

A property journey designed for distance

The diaspora journey is planned around remote property discovery, visible verification records, guided inspections and direct support. The aim is to reduce dependence on informal intermediaries when the buyer cannot be physically present.

Remote inspection support

Video tours can be requested from the property page and tied to the same enquiry journey.

For agents and developers

Property inventory is expected to enter OgaProp through accountable participant profiles. Listing information, supporting documents and verification requirements can then be attached to the same property record.

The transaction journey

The longer-term flow is discovery → verification → enquiry → inspection → offer → payment or financing → completion. The current presentation focuses on discovery, verification visibility, enquiry and inspection support.
